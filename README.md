# AI Arena

AI Arena is an interactive exhibit involving locally hosted AI models.

## Current status

The project currently contains an early Python controller prototype. It verifies that Python can send a message to a locally running Ollama model and receive its response.

This prototype is a starting point and is not the final arena controller.

## Requirements

- Python
- Ollama
- A locally installed Ollama model
